************
AIA Examples
************

These examples use the bundled AIA response file together with the local FITS fixtures
stored under ``demregpy/tests/data/aia`` and ``demregpy/tests/data/aia_flare``.
They also include small response-only examples for plotting the bundled AIA response curves
and for generating synthetic AIA counts.
They also include a loci example showing how the AIA channel set constrains a
single-pixel DEM.

They are kept small enough for the documentation build while still showing
typical AIA workflows.
